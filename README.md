# WARFRONT FIVE — Version 2.8: USA Base, Terrain & Simulated Traffic

A multiplayer **fictional strategy game** for up to five players. It combines an internet-connected real-world reference map with completely made-up team bases, aircraft, cars, license plates, traffic lights, traffic jams, units and visual game effects. **It does not locate or track real planes, road traffic, military sites, vehicles, or weapons.**

## Added in v2.8

### Fictional U.S. base
- Each team starts with a fictional base marker in a generic U.S. city area. Neither location represents a real military facility.
- Use **MY BASE** (under the map) or **GO TO BASE** (in the left panel) to zoom there.
- To change your team's base, click **MOVE BASE**, then click a U.S. map position. Other connected players see the new team-base marker.
- The map accepts simulated base placements within broad U.S. regions, including the contiguous states, Alaska, and Hawaii.
- Base positions reset to fictional defaults when the server restarts.

### Map layers & camera-style map modes
- **TERRAIN:** World Topographic basemap using online Esri tiles.
- **STREETS:** OpenStreetMap street tiles.
- **SATELLITE:** Online Esri imagery basemap.
- **NORMAL / RGB / HEAT / NIGHT VISION:** Visual styles applied to the **map imagery**, not the rest of the interface.
- RGB mode includes individual red, green and blue sliders. Heat and night-vision palettes are cosmetic color effects, **not thermal or low-light sensors**.
- The existing full-UI and War Cam filters (grit, grit size, hue, saturation, brightness and glitch) still work separately.

### Simulated aircraft and road cars
- Six artificial aircraft travel around the fictional team base; their flight IDs, paths, altitudes and motion are all generated by the browser. **They do not represent live air traffic.**
- Cars use invented `SIM-####` plate labels. Their positions, speeds and movements are generated by the browser; **no actual license plates, GPS, or live vehicle feeds are used**.
- Cars use OpenStreetMap road **geometry** when the public Overpass endpoint is available. If that lookup fails, cars immediately continue driving on a **clearly labeled fictional grid overlay**, which may not match the real-world streets beneath it.
- Cars pause at simulated red lights and occasionally get stuck in made-up traffic jams before continuing.
- Air traffic and road cars can be toggled independently. The road-car count is adjustable (2 to 18).
- These ambient aircraft/car animations run **locally on each device**. Only team base relocation is sent to other connected players.

## Previous features kept
- Five players maximum, Red and Blue teams, team chat, WebRTC private voice/video calling, permission-controlled War Cam.
- Simulated map placements and game effects; no real weapon control.
- All uploaded photo galleries: missiles, tanks, jets, UAVs, ATVs, signal truck, support truck and field truck.
- Previous filters and the sharp-edged dark interface.

## Setup (GitHub + Render)

1. Extract the ZIP. Upload the **contents** to a GitHub repository, not an enclosing folder. `server.js` and `package.json` must be at the repository root, with the `public` folder beside them.
2. Deploy as a **Render Web Service**. Use build command `npm install` and start command `npm start`.
3. Open your Render website's HTTPS link. Join with a callsign and choose a team.
4. Use the **BASE / WORLD SIM** controls in the left panel. On phones, the quick **MY BASE / MOVE BASE** buttons also appear below the map.
5. Press **GO TO BASE** and try Terrain, RGB, Heat, and Night Vision using the controls directly beneath the map.

The app uses **Node.js 18+** with no npm package dependencies. To test it locally, run `npm start` and open `http://localhost:3000`.

## Requirements & limitations

- The real basemap tiles need internet. The public tile and road-geometry services can be slow or rate-limited, which is why an immediate **fictional road fallback** is included.
- The public Overpass service is intended for light use; frequent base changes can be throttled or unavailable.
- Camera/microphone permission requires HTTPS outside localhost. Some peer-to-peer calls require additional TURN relay support depending on networks.
- The browser-only traffic movement doesn't represent real traffic signals, actual traffic conditions, actual flights, or validated vehicle behavior.
- This is a fictional multiplayer prototype, not a secure or reliable service for emergency response, military use, or navigation.
